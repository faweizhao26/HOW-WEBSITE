# 后台编辑体验收尾

用户批准三项：直接上传图片/PDF、发布前草稿预览、具体校验与未保存提示。
本批基于已发布的 `5cab12b`，不修改正式业务资料，也不接入邮件或短信。

1. 复用 `conference-media` 和管理员权限，直接上传 PNG/JPEG/WebP/GIF 或 PDF。
   新文件使用随机路径，不覆盖旧素材；失败不改链接，成功后仍属于未保存草稿。
   文件格式、大小和实际响应确认后才能显示成功，上传时暂停保存及发布。
2. 新增管理员预览页与 iframe 预览窗口，向 iframe 传递当前编辑内容，不写入数据库。
   与前台共用页面展示组件，支持页面、语言及真实手机/桌面宽度；公开页仍只读发布版本。
3. 校验结果包含字段路径、栏目名称和双语错误，点击能展开栏目并定位控件。
   刷新/关闭通过 beforeunload 提醒，站内链接离开通过放弃修改确认；不自动发布或保存。

验收：文件上传及错误行为单元测试、管理员授权和预览数据验证、完整回归及 lint/build，
隔离环境实际上传/保存/预览、公开草稿隔离、错误定位、离开取消及放弃，以及手机/桌面显示。
生产发布另以明确推送指令为准，完成后先交付可检查的本地预览。
