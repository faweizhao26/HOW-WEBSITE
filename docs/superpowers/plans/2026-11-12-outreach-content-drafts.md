# Outreach Content Drafts Implementation Plan

**Goal:** 后台预留赞助方案、宣传资料、讲者指南和首页筹备进展，新增模块默认关闭，资料为空不出现在前台。

**Architecture:** 扩展现有 site_content JSON，旧发布记录解析时补入独立的关闭默认值。复用设置草稿、媒体上传、预览、发布及回滚；生成数据库 JSON Schema 校验迁移。页面和入口均以同一个可见性规则控制，不改变旧栏目、日期、场地或票务。

**Design:** 赞助等级可添加、排序、删除，配置双语名称、价格说明、名额说明、权益及资料链接。宣传与讲者指南采用既有双语图文/链接栏目；只有启用并有实际资料才开放独立路由及入口。首页筹备进展独立开关与图文栏目，无自动编造内容。附件上传继续支持图片/PDF，其他格式可填外部链接。

## Tasks
- [x] 1. 添加旧数据兼容、默认隐藏、空内容、链接校验和草稿保留测试，实现模型与统一可见性。
- [x] 2. 后台编辑器、预览、前台展示与条件入口；未开放路由返回 404，保持现有页面不变。
