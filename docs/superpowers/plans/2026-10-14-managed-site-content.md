# 后台运营内容与合并发布

用户已批准把可维护的运营内容转到后台，并与票务/征稿配置一起推送正式环境。
使用现有设置草稿、整版发布及回滚，不建立另一套 CMS 或开放布局、样式代码。

1. 内容契约与后台编辑：`site_content` JSON 保存会场、专用联系邮箱、首页栏目、
   关于大会、参会指南、赞助招募、问答和条款。类型化校验，禁止可执行链接；
   普通表单编辑双语内容及栏目列表，支持新增、删除、上下移动、启停。
   旧发布版本使用现有内容默认值，未确认场地保持待公布。
2. 公开读取：各页面只读取已发布设置，读取/解析错误显示不可用，不泄漏草稿。
   问答时间、地点、征稿开关和票务入口引用真实公开配置，其他答案后台维护。
   普通文字由 React 转义，不开放原始 HTML；图片与附件为受校验的链接。
3. 验收与发布：类型化内容单元测试、完整回归、lint/build、隔离真实后台保存/发布/
   回滚、显示和链接检查。清理测试内容，应用已验证 CFP 迁移到生产；使用
   faweizhao26 提交并推送当前批次及上一批，确认 Production READY 及正式只读页面。

复核重点：错误不得回退为成功内容；空列表与禁用栏目不得被默认值覆盖；
草稿不得进入问答或公开页；更改联系邮箱后所有对应位置一致；新配置发布后
各路由与全局问答缓存更新。生产不导入测试内容、不创建测试报名、不改变邮件/短信设置。
