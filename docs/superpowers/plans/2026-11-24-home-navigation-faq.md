# Home, Navigation and FAQ Implementation Plan

**Goal:** 落实大会名称优先的首页、清晰导航、可浏览 FAQ；按后续用户反馈撤回分组导航。

**Design:** 保留网络画布和后台文案，以 conference_name 为 H1，口号与副标题降为辅助，日期/城市和主要按钮集中，统计改为无卡片信息带。导航恢复全部既有平铺入口和独立投稿按钮，保留当前页高亮，移动端显示单层完整列表；管理员与登录状态规则不变。首页 FAQ 使用原生 details，并接入后台预览；固定的事实类问题使用现有 getConferenceAnswer，补充问答直接读取已发布的启用条目，不新增数据库字段。

**Architecture:** 复用 HomeView、Header、conference-faq 及预览框架，无新依赖、数据库迁移或生产写入。六个默认补充主题配完整问题标题，自定义问答使用当前语言的首个关键词作标题，缺失时跨语言回退；隐藏停用或空答案。
