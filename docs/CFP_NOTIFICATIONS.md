# 征稿和站内通知

## 征稿

无需账号即可投稿，不需要报名参会或提供手机号。访客填写联系邮箱、确认隐私条款，
成功后可记下提案编号；不发送自动邮件，不开放公开查询，邮箱不随议题公开。
访客邮箱未经验证，管理员在「提案管理」按录取、候补或未录取筛选后，可导出邮箱和对应的提案标题。
账号投稿仍可在「我的提案」中查看进度、接收站内通知。新提案使用一种语言，
默认跟随进入网站时的界面语言，也可单独切换投稿语言。

标题、简介、姓名、单位、职位和个人简介必填；账号投稿的照片选填，可沿用本人账号头像或单独上传
不超过 5 MB 的 JPEG、PNG 或 WebP；访客无需提交照片。普通演讲、工作坊和圆桌须提供大纲，
闪电演讲的大纲选填。讲者资料按本次提案保存，不覆盖账号资料，已有提案不用补填。

| 议题类型 | 时长（分钟） |
| --- | --- |
| 普通演讲 | 30 |
| 工作坊 | 30、45、60 |
| 圆桌讨论 | 30、45、60 |
| 闪电演讲 | 5 |

审核状态为待审核、已录取、候补和未录取。候补可手动转为录取或未录取，不自动递补。
审核结果、站内通知和公开发布是独立操作。录取不会直接公开议题，也不会自动发通知。
已公开的提案先下架再转候补；已发布的议程快照不会自动重写，如需调整请更新并重新发布议程。

## 通知和邮箱导出

在后台「站内通知」筛选所有注册账号、尚未确认参会、已确认参会、
已录取、候补或未录取的提案，或手动选择指定人员。

- 大会信息、报名和讲者安排使用通用通知，按账号去重。
- 审核通知逐篇提案处理，收件箱显示发送时该提案的标题和结果。
  有其他提案通过的投稿人，仍可收到针对未通过提案的通知。
- 发送前预览名单和正文；名单或结果变化须重新预览。同一发送请求重试不会重复投递。
- 通用 CSV 只保留姓名和邮箱；按提案导出保留区分议题的字段。没有接入新的邮件服务，
  注册确认和密码找回邮件不变。发邮件时使用自己的邮箱。
- 用户登录后可在「通知」查看并标记已读。通知并不是站外送达或手机推送。

## 部署

使用现有 Supabase 项目时，按文件名顺序应用
`20261126043826_site_notifications.sql` 和 `20261126043832_cfp_submission_details.sql`，
再应用 `20261127151032_guest_cfp_submissions.sql`，最后更新网站代码或 Docker 镜像。
不要对现有数据库重放基础 schema，也不要重新应用已记录的迁移。
前两份迁移和访客投稿迁移已分别于 2026-11-26 和 2026-11-27 应用至 Vercel 正式站使用的 Supabase 项目，
文件版本号与该项目的迁移记录一致。访客投稿限同一邮箱每小时 5 次、
全站每 10 分钟 60 次，重复提交同一请求不计新提案。
征稿迁移会立即校验新提案字段，应用迁移和切换应用版本应在同一维护窗口完成。
两份迁移不重写已发布设置和历史提案；如当前已发布的设置明确选择了旧的类型列表，
在后台征稿设置勾选「闪电演讲」并发布，即可开放。

站内通知和邮箱筛选只在管理员侧操作；通知收件箱只返回登录账号自己的记录。
使用 `scripts/verify-site-notifications.sql`、`scripts/verify-cfp-intake.sql`、`scripts/verify-cfp-waitlist.sql` 和 `scripts/verify-cfp-guest.sql`
在已迁移的隔离数据库验收，测试数据会回滚。

本地预览使用模拟登录和真实隔离 PostgreSQL，没有调用正式 Auth、Storage 或业务接口。
已验收中英文、桌面/390px 浏览器工作流；实际部署环境的 Storage 上传、生产邮件与历史数据未动。
