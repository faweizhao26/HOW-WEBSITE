# 胸牌打印配置

日期：2026-10-19。分支：`codex/configurable-badge-printing`，基线：`07e3587`。
状态：本地实现与验收完成，用户已授权推送和 Production 发布；无数据库迁移、无正式业务写入。

## 配置入口

后台 → 站点设置 → 胸牌打印。管理员可设置：

- 纸张宽度 40–150 mm、高度 25–150 mm、内边距 0–8 mm；内容区至少 30 × 17 mm。
- 黑白标签或绿色彩印样式。
- 是否显示大会名称、单位、票种；姓名固定显示。大会名称取站点设置，票种取实际报名记录。
- 虚拟姓名和单位仅用于当前页面的样张预览、试打，不保存为参会资料或打印配置。

配置使用现有 `site_settings` 的可选 `badge_print` JSON 字符串，随整版设置保存、发布和回滚。
未保存或未发布的草稿不影响现场打印；每次签到打印读取当前已发布版本，失败时提示重试，
不悄悄套用其他尺寸。旧发布版本没有该键时，兼容 90 × 55 mm 彩印默认值。
默认版式改为纵向排列，保留姓名、单位和票种，单位不再省略截断。

## 打印行为

后台 → 签到，搜索参会人，确认签到后点击打印。仍需确认系统打印对话框，不是无人值守自动出纸。
同步打开窗口后再读取配置，避免异步请求导致弹窗被拦截；加载期间禁止重复打印和签到切换。
打印模板与预览共用生成和文字适配逻辑，文本全部转义，不执行模板内脚本或外部资源。
长文本按字段比例缩小并换行；仍超出纸张时不调用打印，提示增大尺寸或减少显示字段。

实际设备尚未选择，未做实体试打。现场需在打印机驱动中设置对应标签纸尺寸，使用 100% / 实际大小、
关闭页眉页脚；彩印需允许背景图形。网页不能代替安装驱动、选择打印机或校准走纸。
本功能不包含二维码扫描、打印任务历史、批量打印、静默打印或打印成功回执。
