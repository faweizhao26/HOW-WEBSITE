# 后台手机导航

更新：2026-10-17。工作分支 `codex/admin-mobile-navigation`，本地完成，未提交、未推送。

## 范围

手机后台不再使用横向滑动菜单，改为原生可展开导航。
收起时显示当前栏目，展开可访问全部 11 个后台栏目；较宽手机使用两列，窄屏使用单列。
菜单高度受视口约束，长菜单纵向滚动，退出入口位于独立底部区域。
换页后重新收起；点击当前栏目也收起。Enter/空格可展开，Esc 收起并把焦点返回标题。
当前栏目使用 `aria-current="page"`，嵌套页面匹配所属栏目，不误匹配同名前缀。
电脑端保留 240px / 64px 侧栏，折叠状态跨后台页面保留，并补齐图标按钮名称及焦点提示。

展示导航独立到 `src/components/admin/navigation.tsx`；
`src/app/admin/layout.tsx` 保留原有登录、管理员角色检查、退出处理及预览页面分支。
未修改业务接口、角色规则、数据库、邮件或短信服务。
